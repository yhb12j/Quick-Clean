# VK-services-bot

Бот-каталог клининговых услуг для сообщества ВКонтакте «Чисто и Быстро» (Long Poll, vkbottle).

## Возможности

- Главное меню: «📋 Услуги», «💰 Прайс-лист», «☎️ Связаться с менеджером» (зелёная кнопка)
- Список услуг из `services.json` в 2 столбца с переходом к карточке каждой услуги
- Карточка услуги: название, описание, фиксированная стоимость
- Прайс-лист со стоимостью всех услуг
- Контакты менеджера (телефон из `.env`) — навигация возвратом в главное меню
- Вся навигация — inline-кнопками, сообщение редактируется (без спама)

## Структура проекта

- `bot.py` — точка входа, запуск бота (Long Poll) и обработчики сообщений/кнопок
- `config.py` — загрузка токена и настроек из `.env` (python-dotenv)
- `keyboards.py` — генерация inline-клавиатур (Callback-кнопки)
- `services.py` — чтение каталога услуг из JSON, иконки, поиск по id
- `services.json` — данные об услугах (6 клининговых услуг, фиксированные цены)
- `prompt.md` — техническое задание

## Запуск

1. Создайте виртуальное окружение и установите зависимости (при ProxyError/Timeout используйте флаг `--default-timeout=100` или зеркало PyPI):

   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt --default-timeout=100
   ```

2. Скопируйте `.env.example` в `.env` и заполните свои данные:

   ```powershell
   copy .env.example .env
   ```

3. Запустите бота:

   ```powershell
   python bot.py
   ```

В настройках сообщества включите «Сообщения сообщества» (Long Poll, режим ВКЛ), разрешите сообщения и выдайте боту права администратора.
