# Техническое задание: VK-бот каталога клининговых услуг «Чисто и Быстро»

## 1. Цели проекта

Разработать полностью рабочего бота сообщества ВКонтакте (Long Poll API), который:

- повторяет интерфейс, логику переходов и структуру файлов эталонного проекта преподавателя;
- работает на базе расширенного каталога клининговых услуг с фиксированными ценами;
- предоставляет пользователю главное меню, список услуг, карточки услуг, прайс-лист и контакты менеджера;
- полностью управляет навигацией через inline-кнопки (callback-кнопки), редактируя одно и то же сообщение (без спама новыми сообщениями).

## 2. Используемые технологии

- **Python 3.10+** — основной язык;
- **vkbottle 4.11+** — асинхронный фреймворк для ботов ВКонтакте;
- **Long Poll API** (`bot.run()`) — режим работы бота (не Webhook);
- **callback-кнопки** (`vkbottle.Callback`, inline-клавиатура) — навигация;
- **`MessageEventMin`** (`vkbottle.tools.mini_types.bot`) — перехват нажатий на callback-кнопки через `@bot.on.raw_event("message_event")`;
- **python-dotenv** — чтение токена группы из файла `.env`;
- **JSON** — файл каталога услуг `services.json` (данные отделены от кода).

## 3. Структура проекта

```
VK-services-bot/
├── bot.py            # точка входа: обработчики сообщений и callback-кнопок (Long Poll)
├── config.py         # чтение токена группы и настроек из .env (python-dotenv)
├── services.py       # чтение каталога из services.json, поиск по id, иконки услуг
├── keyboards.py      # генерация inline-клавиатур на базе Callback-кнопок
├── services.json     # каталог клининговых услуг с фиксированными ценами
├── requirements.txt  # список библиотек (vkbottle, python-dotenv)
├── .env              # токен сообщества, ID группы, телефон менеджера (не публиковать!)
├── .env.example      # шаблон .env
└── prompt.md         # настоящее техническое задание
```

## 4. Каталог услуг (`services.json`)

Плоский JSON-массив из 6 коммерческих услуг клининга, фиксированные цены:

| id | Название | Цена | Эмодзи-иконка |
|----|----------|------|---------------|
| `dry_carpet` | Химчистка ковра | 1200 Р | 🧺 |
| `dry_sofa` | Химчистка дивана | 2500 Р | 🛋️ |
| `window_wash` | Мытье окон | 1600 Р | 🪟 |
| `general_flat` | Генеральная уборка | 4900 Р | ✨ |
| `ironing_basket` | Глажка белья | 1500 Р | 👔 |
| `kitchen_deep` | Уборка кухни | 3200 Р | 🍳 |

Пример элемента:

```json
{"id": "dry_sofa", "name": "Химчистка дивана", "price": "2500 Р", "description": "Профессиональная экстракторная чистка трехместного тканевого дивана специальными гипоаллергенными составами."}
```

Эмодзи-иконки хранятся отдельной таблицей в `services.py` (`SERVICE_ICONS`) и используются одновременно в подписях кнопок и в прайс-листе.

## 5. Логика работы кнопок и переходов

### Payload-команды

| Payload | Действие |
|---------|----------|
| `{"cmd": "menu_services"}` | раздел «📋 Услуги» — список услуг |
| `{"cmd": "menu_price"}` | раздел «💰 Прайс-лист» |
| `{"cmd": "menu_manager"}` | раздел «☎️ Связаться с менеджером» |
| `{"cmd": "service", "id": "<id услуги>"}` | карточка конкретной услуги |
| `{"cmd": "to_main"}` | возврат в главное меню |

### Шаг 1. Старт

Триггеры: `Начать`, `Привет`, `start`, `/start` (регистронезависимо).

Текст:

```
Добро пожаловать в клининг-центр **Чисто и Быстро**!
Выберите интересующий раздел.
```

Клавиатура (главное меню):

- строка 1: `📋 Услуги` | `💰 Прайс-лист`;
- строка 2: `☎️ Связаться с менеджером` — зелёная кнопка (`color="positive"`).

### Шаг 2. Раздел «📋 Услуги»

Текст: `Выбери услугу:`

Клавиатура — список из `services.json` в 2 столбца:

- строка 1: `🧺 Химчистка ковра` | `🛋️ Химчистка дивана`
- строка 2: `🪟 Мытье окон` | `✨ Генеральная уборка`
- строка 3: `👔 Глажка белья` | `🍳 Уборка кухни`
- строка 4: `🏠 Главное меню` (на всю ширину, payload `{"cmd": "to_main"}`)

### Шаг 3. Карточка услуги

Формат текста строго:

```
**[Название услуги]**

[Описание услуги]

**Стоимость:** [Цена из JSON, напр. 2500 Р]
```

Клавиатура в один ряд: `⬅️ Назад` (к списку услуг) | `🏠 Главное меню`.

### Шаг 4. Раздел «💰 Прайс-лист»

Текст — список, формируется циклом из JSON:

```
**# Прайс-лист**

🧺 Химчистка ковра — 1200 Р
🛋️ Химчистка дивана — 2500 Р
🪟 Мытье окон — 1600 Р
✨ Генеральная уборка — 4900 Р
👔 Глажка белья — 1500 Р
🍳 Уборка кухни — 3200 Р
```

Клавиатура — единственная кнопка `🏠 Главное меню`.

### Шаг 5. Раздел «☎️ Связаться с менеджером»

Текст:

```
Наш менеджер ответит вам в ближайшее время.

**Телефон:**
+7 (900) 123-45-67

Или напишите в сообщения сообщества.
```

Клавиатура — снова главное меню (Услуги, Прайс-лист, Связаться с менеджером).

### Технические требования к обработчику кнопок

- Нажатия перехватываются через `@bot.on.raw_event("message_event", dataclass=MessageEventMin)`.
- Сразу вызывается `event.send_empty_answer()` — подтверждение нажатия (иначе VK держит анимацию загрузки ~15 секунд).
- Ответ формируется чистой функцией `build_reply(payload) -> (text, keyboard_json)`.
- Сообщение обновляется через `event.edit_message(text, keyboard=...)` **внутри обязательного try-except**: при любой ошибке анимация загрузки гасится, ошибка логируется, бот не падает.

## 6. Ожидаемый результат

- Бот запускается командой `python bot.py` и работает через Long Poll.
- Все переходы выполняются inline-кнопками без пересылки новых сообщений (сообщение редактируется).
- Тексты, эмодзи, цены и клавиатуры полностью соответствуют разделу 5.
- Каталог услуг вынесен в `services.json`: добавление новой услуги = добавление объекта в массив (код менять не нужно, если добавить иконку услуги в `SERVICE_ICONS` в `services.py`).
- Ошибки обработки кнопок не роняют бота и не оставляют кнопку в зависшем состоянии.

## 7. Настройка и запуск

1. Создать виртуальное окружение и установить зависимости (см. команды ниже).
2. Заполнить `.env` по шаблону `.env.example` (токен группы, ID группы, телефон менеджера).
3. В настройках сообщества: «Сообщения сообщества» → включить, режим «ВКЛ» (Long Poll), разрешить сообщения; выдать боту права.
4. Запустить: `python bot.py`.

### Команды для терминала (Windows PowerShell, обход Proxy/Timeout)

```powershell
# 1) Виртуальное окружение
python -m venv venv

# 2) Активация окружения
.\venv\Scripts\Activate.ps1

# 3) Обновление pip с увеличенным таймаутом
python -m pip install --upgrade pip --default-timeout=100

# 4) Установка библиотек (основной вариант, с большим таймаутом)
python -m pip install vkbottle python-dotenv --default-timeout=100

# 4а) Если ProxyError/TimeoutError всё равно возникает — зеркало PyPI (Яндекс):
python -m pip install vkbottle python-dotenv --index-url https://mirror.yandex.ru/mirrors/pypi/simple/ --default-timeout=100

# 4б) Альтернативное зеркало (Tsinghua):
python -m pip install vkbottle python-dotenv --index-url https://pypi.tuna.tsinghua.edu.cn/simple --default-timeout=100

# 5) Запуск бота
python bot.py
```

Примечание: если активация `.ps1` запрещена политикой выполнения — `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`, затем активировать повторно.
